API Endpoint Reference

Detailed REST specifications for our quantitative analytics core. All endpoints require a valid header token for authentication.

GET /api/v1/signals/latest

Fetch the latest volatility-adjusted trading signals, confidence ratios, and estimated alpha bounds.

Query Parameters:

  • ticker (string, required): Ticker symbol. E.g. BTCUSD.

Response Example (200 OK):

{{
  "ticker": "BTCUSD",
  "signal": "BUY",
  "confidence": 0.8872,
  "metrics": {{
    "alpha": 0.0321,
    "sharpe": 2.4182
  }}
}}
POST /api/v1/signals/validate

Perform a Convergent Cross Mapping (CCM) causality test on the provided data points to audit structural drivers.

Request Body (JSON):

{{
  "cause": "BTCUSD",
  "effect": "ETHUSD",
  "data_points": [102.5, 103.1, 101.9, ...]
}}

Response Example (200 OK):

{{
  "causality_validation": {{
    "ccm_strength": 0.7924,
    "converged": true
  }},
  "monte_carlo_projections": [[101.5, 102.8, ...], ...]
}}

POST /api/v1/signals/volatility

Calculate rolling volatility, GARCH-estimated annualized volatility, and estimated Sharpe ratios.

Request Body (JSON):

{{
  "ticker": "BTCUSD",
  "data_points": [95.0, 97.2, 96.5, ...]
}}

Response Example (200 OK):

{{
  "ticker": "BTCUSD",
  "rolling_std_vol": 0.021,
  "annualized_volatility": 33.34,
  "approx_sharpe_ratio": 2.12,
  "mean_daily_return": 0.0015
}}
