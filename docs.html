Programmatic Checkout & Subscriptions

To support programmatic usage by LLM agents, AetherQuant offers a dedicated billing agent subscriber endpoint. This allows an agent to request a subscription. If the user has a saved payment method in their Stripe profile, it charges the card and provisions the subscription instantly; otherwise, it returns a Stripe Checkout URL for manual completion.

POST /api/v1/billing/agent-subscribe 
curl -X POST https://aetherquant.cloud/api/v1/billing/agent-subscribe \
  -H "Content-Type: application/json" \
  -d '{
    "user_email": "agent-runner@yourcompany.com",
    "plan_id": "pro"
  }'

Response JSON (Immediate Activation):

{
  "status": "active",
  "subscription_id": "sub_1ThZHu4k2kNCVVeN...",
  "message": "Subscription programmatically activated and charged to default payment method."
}

Response JSON (Fallback Checkout):

{
  "status": "pending_payment",
  "checkout_url": "https://checkout.stripe.com/pay/cs_live_...",
  "message": "No default payment method saved. Complete payment via the checkout URL."
}

Model Context Protocol (MCP) Server Setup

If you are running Claude Desktop or Cursor, you can register AetherQuant as an MCP tool server to pull live signals and run causal validations natively.

Add the following configuration block to your claude_desktop_config.json or Cursor settings file:

{
  "mcpServers": {
    "aetherquant": {
      "command": "npx",
      "args": ["-y", "aetherquant-mcp-server"],
      "env": {
        "AETHERQUANT_API_KEY": "YOUR_API_KEY",
        "AETHERQUANT_API_URL": "https://aetherquant.cloud"
      }
    }
  }
}

Exposed MCP Tools:

  • get_latest_signals: Retrieve real-time trade signals and alpha/Sharpe metrics.
  • verify_causality: Reconstruct delayed coordinate attractor manifolds using CCM.

REST API Reference

Secure all requests by passing your generated API key in the authorization header: Authorization: Bearer YOUR_API_KEY.

1. Create Developer Key

POST /api/v1/keys/create 
curl -X POST https://aetherquant.cloud/api/v1/keys/create \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"

2. Get Latest Quantitative Signals

GET /api/v1/signals/latest 
curl -X GET https://aetherquant.cloud/api/v1/signals/latest \
  -H "Authorization: Bearer YOUR_API_KEY"

3. Run Causality Validation (CCM)

POST /api/v1/signals/causality 
curl -X POST https://aetherquant.cloud/api/v1/signals/causality \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "target_series": "BTCUSD",
    "driver_series": "API_CALLS"
  }'
