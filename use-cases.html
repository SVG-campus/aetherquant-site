Current production use case

Evidence-led market research workflow

AetherQuant keeps a market question, approved data context, evidence references, and research notes together in an account-scoped workspace.

Open secure workspaceRead API and MCP docs

Who it is for

Research teams, analysts, and builders who need a reviewable market-research record before making a separate decision.

Workflow

01

Frame

State the research question, instruments, time horizon, and assumptions before reviewing evidence.

02

Record

Keep approved market-data context, evidence references, and research notes in the same account-scoped workspace.

03

Review

Treat outputs as research context. A person validates data quality and makes every investment or trading decision separately.

Boundaries

What the product deliberately does not do

  • No investment advice or automatic trading
  • No promise that a historical relationship persists
  • No model, IDE, or general-purpose AI product

Account scope

One customer, one workspace boundary

Authentication, entitlements, usage, API keys, saved artifacts, and billing state are verified server-side. Product keys are revocable and work only for their own product account.

Agent access

MCP without browser credentials

The customer-installed MCP bridge reads a product key from its local process environment and exposes only the documented account-scoped workflow.

Questions

Does AetherQuant make trades?

No. It organizes market-research context; it does not place orders or make investment decisions.

Are public examples live signals?

No. Only authenticated API and workspace responses describe account-specific data and access.

Can an agent use it?

Yes, through the documented account-scoped API and customer-installed MCP bridge with a revocable product key.
